# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in italailabs.com or
this repository, please report it to us privately:

- **Email:** [research@italailabs.com](mailto:research@italailabs.com)

Please do **not** open a public GitHub issue for security problems. Public
disclosure can expose visitors before a fix is in place.

If available, include:

- A description of the issue and where it lives
- Steps to reproduce, or a proof of concept
- Any impact assessment

## Response

We aim to acknowledge reports within 5 business days and will keep you
informed while we assess and fix the issue.

## Scope

- The static website at <https://italailabs.com> (this repository)
- The GitHub Actions workflows that build and deploy it

**Out of scope:** vulnerabilities in third-party services (e.g., Google
Analytics, Formspree, Google Fonts) — please report those to the respective
provider.

## Secure communication

If you have an encrypted channel (PGP key, Signal, …), include or reference
it in your report so we can respond securely.
